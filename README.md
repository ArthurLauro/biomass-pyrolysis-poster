# biomass-pyrolysis-poster

Scientific conference poster (HTML/CSS) for:
**Development of a Digital Twin Framework for a Biomass Pyrolysis Reactor Applied to Biochar Production**

## Open locally

From the repository root, open `index.html` in a browser.

## Printing guidance

Use your browser print dialog and select a large landscape format (recommended: A0 landscape) for conference poster output.
If your browser ignores CSS page settings, manually enable landscape orientation, A0 paper size, margins close to 10 mm, and background graphics/colors in the print dialog.
